# User Guide

The CICT Asset Management System (CICT-AMS) provides a centralized, auditable platform for university academic departments. It replaces paper-based inventory with real-time digital tracking, QR code verification, role-based security, and complete lifecycle management for institutional assets.

This guide covers the workflow for each tab in the application.

| Tab | What it's for |
|---|---|
| [Assets](assets.md) | Register, search, and tag equipment |
| [Dashboard](dashboard.md) | Department-wide overview |
| [Audit](audit.md) | Physical inventory reconciliation |
| [Reports](reports.md) | Incident and maintenance tracking |
| [Transfers](transfers.md) | Relocations and chain of custody |
| [Rooms](rooms.md) | Spatial inventory |
| [Custodians](custodians.md) | Accountability and PAR/ICS |
| [Settings](settings.md) | Profile, notifications, system configuration |
