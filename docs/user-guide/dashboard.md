# Executive Dashboard (Dashboard Tab)

The Dashboard gives department heads and system administrators a high-level overview of equipment, room usage, and active incidents.

## Summary Metrics

Live counters show key inventory statistics:

* **Total Assets**: All registered equipment currently active in the database.
* **Total Rooms**: Monitored physical locations and computer laboratories.
* **Active Custodians**: Faculty and staff members holding property accountability.
* **Unresolved Incidents**: Active damage or missing-property reports needing administrative action.

## Inventory Condition Breakdown

Visual charts show the condition profile of all department assets: Working, Damaged, For Repair, Missing, and Condemned.

## Recent Activity Feed

An automated activity stream logs operational events as they happen, including asset registrations, room transfers, incident submissions, and status updates. This gives immediate accountability without manual record checks.
