# Spatial Inventory Management (Room Tab)

The Room tab organizes department assets by physical location, building floor, and laboratory.

## Room Directory

Each room card shows the room number or name, room type (for example Computer Lab, Lecture Hall, Office), the primary custodian, and the number of assets in the room.

## Room Asset List

Selecting a room card opens its full inventory: assigned equipment, asset tag IDs, conditions, and secondary custodians.

## Location Management

Administrators can create room records, update capacities, assign laboratory supervisors, and view past audit reports for each room.
