# System Configuration & Settings (Settings Tab)

The Settings tab holds personal preferences and administrative configuration.

## User Security & Profile

Users can update profile details, manage security settings, change their password, and manage linked sign-in accounts (BulSU Microsoft Entra ID or Google).

## Notification Preferences

Configure email and in-app alerts for asset assignment, transfer requests, incident status updates, and scheduled audit reminders.

## Administrative System Configuration

Administrators can adjust system-wide settings:

* **Asset ID Formatting**: View or set the default asset ID prefix (`cict-XXXX`).
* **QR Sticker Printing Templates**: Choose default label sizes (for example a 2x2 inch grid) and toggle branding such as the college logo or room name on printed QR tags.
* **Database Backup & Data Export**: Export system tables (Assets, Custodians, Rooms, Incident Logs) as CSV or JSON for university compliance archives.
